# LumaSlice · LCD 切片工作台

用于 LCD/MSLA 的独立 Windows 桌面切片软件。模型按毫米读取，仅输出逐层 PNG 曝光图与配套任务信息。

## 启动

便携版：解压整个文件夹，双击 `LumaSlice.exe`。必须保留同目录的 `_internal` 文件夹。
如需桌面入口，双击包内的 `Create-DesktopShortcut.vbs`；它会为当前解压位置创建桌面快捷方式。

源码版：安装 Python 3.11 或更新版本，执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

依赖已安装后可双击 `Start-LumaSlice.bat`。运行时无需网络。

## 使用

1. 启动时显示 Ø40 mm、内孔 Ø18 mm、高 10 mm 的校准圆环。点击「移除」后导入自己的 STL、OBJ 或 PLY，也可直接拖入模型。
2. 设置屏幕 X/Y 分辨率、打印宽度/深度、最大高度和层厚。默认 11520 × 5120 px，218.88 × 97.28 mm，仅作为可修改的示例参数；请填写实际设备尺寸。
   「单像素 X」「单像素 Y」可直接输入物理尺寸，单位 μm（1 μm = 0.001 mm），两个方向独立设置。修改像素尺寸时保持分辨率不变，自动更新打印宽度/深度；修改打印面积或分辨率时自动重算像素尺寸。三者始终满足「打印尺寸 = 像素数量 × 单像素尺寸」。例如 11520 × 5120 像素、单像素 X/Y 均为 20 μm 时，打印面积为 230.4 × 102.4 mm。
3. 对象可居中、复制、平移、旋转及等比缩放。各模型默认在平台中心；导入多个模型后可分别调整位置，重叠区域按实体并集合成。
4. 点击「生成当前层预览」，滚轮放大，可看到实际像素网格与坐标/灰度。「画笔」的灰度可设为 0–255（0 为黑，255 为白），直接覆盖原像素；「擦黑」始终写入 0，两者只作用于当前层。半径 0 表示单个像素。「撤销笔迹」撤销当前层最后一次笔迹。手绘灰度会保存在项目中，并原样带入单层 PNG 和整套 PNG 导出。
5. 点击「切片并导出 PNG」，选择导出位置。软件创建一个新的任务文件夹，生成 `layer_000001.png` 起的图片序列及 `job.json`。PNG 始终保留设置的完整分辨率。
6. 保存 `.lcdproj` 项目会嵌入模型、参数和手绘笔迹，可在另一台安装了本软件的电脑上继续打开。

参数输入框、下拉框和层号滑条不会因鼠标滚轮改变值；请直接输入、使用键盘或点击控件箭头/滑条调整。页面滚动、三维视图和切片预览的滚轮缩放仍可使用。

## 坐标、采样和输出

- 世界原点在打印平台左下角，X 向右、Y 向上，Z 向上；图片原点在左上角。
- 像素尺寸独立计算：X = 打印宽度 / 像素宽度；Y = 打印深度 / 像素高度。支持非正方形物理像素。
- 在每层厚度的中间位置采样，最后不足一层时在剩余区间中间采样。具体高度记录于 `job.json`。
- 8-bit 单通道灰度 PNG。默认 255 为曝光、0 为关闭；抗锯齿关闭时原始几何掩膜只包含 0/255。
- 无默认相机透视、显示缩放或截图参与 PNG 生成。截面经过平面几何运算，再按像素中心取样。
- 「边缘补偿」为像素坐标中的方形膨胀/腐蚀，正值扩大白色，负值收缩。它不等同于已标定的树脂、光学或圆形半径补偿。
- Gamma 使用 `output = 255 * (input / 255) ** (1 / gamma)`，只影响灰度，纯 0/255 不变。
- 手绘记录按层号与原始像素坐标保存。变更层厚/分辨率/镜像/模型后仍保留原坐标；大幅变更前建议另存项目或新建项目。

## 图片处理扩展接口

在右侧加载你信任的 Python 文件，该文件应提供：

```python
import numpy as np

def process(image: np.ndarray, context) -> np.ndarray:
    # image: H × W，uint8，可原位修改，也可返回同尺寸新数组。
    # context.layer_index: 从 0 开始的层号
    # context.sample_z_mm / layer_top_mm / layer_height_mm
    # context.resolution: (W, H)
    # context.build_size_mm: (X, Y)
    # context.pixel_size_mm: (X, Y)
    return image
```

`plugins/identity.py` 是空处理模板；`plugins/radial_gain_example.py` 展示分块处理方式，初始补偿强度为 0。这些文件可直接修改，用于后续接入标定图、曝光均匀性、几何尺寸或局部特征补偿。

统一流程：截面求并集 → 像素取样/抗锯齿 → 边缘补偿 → Gamma → 自定义插件 → 镜像 → 反相 → 当前层手绘 → PNG。预览、单层保存和整套导出使用相同流程。插件输出尺寸或类型错误会中止导出；Python 插件在本机执行代码。

## 当前范围

- 提供模型切片和曝光图导出；不自动生成支撑、挖空或排液孔，不输出 CTB、SL1 或设备通信命令。需支撑的模型可先在其他工具中处理再导入。
- 切片要求闭合且无自交的三角网格。检测到未闭合截面会报错，不会自动填上缺口。复杂非流形、自交网格应在建模工具中修复。
- 单个网格中互相重叠的封闭壳体采用奇偶填充规则；若需实体并集，请分成独立对象导入或先做布尔并集。不同对象之间按实体并集合成。
- 不提供切片质量或打印成功保证；首次上机前核对物理尺寸、曝光极性和方向。
- 单轴最大 65536 px、每层最多 268435456 px，抗锯齿临时区域最多 3 亿采样像素。逐层处理以控制内存，实际速度取决于分辨率和网格复杂度。
- 导出在临时任务目录中逐层生成；仅全部成功后命名为最终任务目录。取消/失败时保留带 `.partial-` 的目录及状态信息，不把未完成图片标记为完整任务。
